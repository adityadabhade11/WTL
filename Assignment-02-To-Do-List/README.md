
# Assignment 2: Dynamic To-do List

## Aim
To create a dynamic To-do List web application using HTML, CSS, and JavaScript.

## Features
- Add new tasks.
- Mark tasks as completed by clicking them.
- Delete tasks by double-clicking them.
- Prevent empty tasks.
- Update the task counter automatically.
- Responsive user interface.
- No page reload required.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open the Assignment-02-To-Do-List folder.
2. Open index.html in a web browser.
3. Enter a task and click Add Task.

## Result
A dynamic To-do List application was created successfully.
