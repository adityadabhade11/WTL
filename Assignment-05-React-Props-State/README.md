
# Assignment 5: React App using JSX, Props, and useState

## Aim
To create a React application using JSX and functional components, pass data using props, and manage state using the useState hook.

## Objectives
- Learn React functional components.
- Understand JSX.
- Pass data from parent to child using props.
- Manage state using useState.
- Handle input events and update the UI dynamically.

## Technologies Used
- React
- JSX
- JavaScript
- Vite
- Node.js and npm

## Features
- Accepts the user's name.
- Displays a personalized greeting.
- Passes the name through props.
- Updates the greeting using useState.
- Responds to input changes without a page reload.

## How to Run
1. Run npm install.
2. Run npm run dev.
3. Open the local URL displayed in the terminal.

## Result
A React application was developed successfully using JSX, functional components, props, and the useState hook.
