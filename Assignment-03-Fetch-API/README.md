
# Assignment 3: Fetch API with Async/Await

## Aim
To fetch data from a public API using JavaScript Fetch API and async/await and display it dynamically on a webpage.

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- JSONPlaceholder public API

## Features
- Fetches user data from a public API.
- Displays user names and email addresses.
- Uses async/await for asynchronous operations.
- Dynamically updates the webpage using DOM manipulation.
- Handles errors.

## How to Run
1. Open index.html in a web browser.
2. Ensure an internet connection is available.
3. Wait for the users list to load.

## Result
User data is fetched from the public API and displayed dynamically on the webpage.
