
# Assignment 4: TypeScript Web App - User Interaction

## Aim
To develop an interactive client-side web application using TypeScript.

## Objectives
- Understand TypeScript and type annotations.
- Handle user events.
- Manipulate the DOM.
- Display data dynamically.

## Technologies Used
- HTML
- TypeScript
- JavaScript
- Node.js and npm

## Features
- Accepts a user's name.
- Displays a personalized greeting.
- Handles button-click events.
- Checks for empty input.
- Compiles TypeScript into JavaScript.

## How to Run
1. Install Node.js and npm.
2. Run npm install.
3. Run npx tsc.
4. Open index.html in a browser.

## Result
An interactive web application was developed using TypeScript to handle user interaction and display a personalized greeting.
