
# Assignment 6: React Axios API Fetch

## Aim
To develop a React application that fetches data from an API using Axios and handles loading and error states.

## Objectives
- Integrate Axios into a React application.
- Fetch data from a public API.
- Use useEffect to perform API requests.
- Use useState to manage data, loading, and errors.
- Display API data dynamically.

## Technologies Used
- React
- JavaScript and JSX
- Axios
- Vite
- Node.js and npm

## Features
- Fetches posts from a public API.
- Displays post titles and descriptions.
- Shows a loading message while fetching.
- Displays an error message when a request fails.
- Uses responsive styling.

## API Used
https://jsonplaceholder.typicode.com/posts

## How to Run
1. Open the project folder in VS Code.
2. Run npm install.
3. Run npm run dev.
4. Open the local URL shown in the terminal.

## Result
A React application was developed to fetch and display API data using Axios, with loading and error handling.
