
# Assignment 7: React Registration Form with Validation

## Aim
To create a React registration form using controlled components and useState, with required-field and email validation.

## Technologies Used
- React
- JavaScript and JSX
- Vite
- HTML and CSS

## Features
- Name and email input fields.
- Controlled components using React state.
- Real-time validation feedback.
- Required-field validation.
- Email format validation using RegEx.
- Success message on valid submission.

## How to Run
1. Run npm install.
2. Run npm run dev.
3. Open the local URL shown in the terminal.

## Result
A React registration form was created with controlled inputs, validation messages, and a success message for valid submissions.
