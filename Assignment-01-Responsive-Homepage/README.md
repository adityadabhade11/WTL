
# WTL Assignment 1 - Responsive Homepage

## Aim
To design and develop a responsive homepage using HTML,
CSS, and Bootstrap.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5

## Features
- Responsive navigation bar
- Hero section with a call-to-action button
- Three service cards
- Responsive grid layout
- Footer section
- Mobile-friendly styling

## How to Run
1. Download or clone the repository.
2. Open the Assignment-01-Responsive-Homepage folder.
3. Open index.html using Live Server.
4. Resize the browser to test responsiveness.

## Learning Outcome
Learned how to create a responsive webpage using
HTML, CSS, Bootstrap components, and the Bootstrap grid system.
